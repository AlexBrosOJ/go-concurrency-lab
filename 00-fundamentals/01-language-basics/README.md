# Основы языка Go

## Цель

Этот модуль знакомит с базовым синтаксисом Go и принципами, на которых строится дальнейшее изучение языка.

Мы разберём переменные, типы данных, константы, операторы, условия, циклы и области видимости. Все примеры собраны в одном файле, чтобы можно было изучать их последовательно и экспериментировать с кодом.

## Как запустить

```bash
go run ./00-fundamentals/01-language-basics
```

## 1. Структура Go-программы

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
```

### `package main`

Каждый файл Go принадлежит определённому пакету. Пакет объединяет связанный код и определяет, как его можно использовать.

`package main` обозначает пакет, из которого можно собрать исполняемую программу.

### `import`

Директива `import` подключает пакеты, функциональность которых нужна программе.

В примере мы подключаем стандартный пакет `fmt`, предоставляющий функции форматированного ввода и вывода.

### `func main()`

Функция `main` — точка входа в исполняемую программу. Когда запускается собранное приложение, выполнение начинается с неё.

Внутри `main` мы размещаем инструкции, которые должны выполняться при запуске программы.

## 2. Переменные

Переменная — именованная область хранения значения определённого типа.

```go
var age int
age = 25
```

Здесь мы объявили переменную `age` типа `int`, а затем присвоили ей значение `25`.

Объявление переменной и присваивание — разные операции. Переменная может быть объявлена отдельно от момента, когда мы узнаём её значение.

### Краткое объявление

```go
name := "Alex"
```

Оператор `:=` одновременно объявляет новую локальную переменную и присваивает ей значение. Тип определяется автоматически на основании выражения справа.

Краткое объявление доступно внутри функций. На уровне пакета для объявления переменных используются формы с `var`.

### Zero values

Если переменная объявлена без явной инициализации, Go присваивает ей нулевое значение соответствующего типа.

| Тип | Нулевое значение |
|---|---|
| Числовые типы | `0` |
| `bool` | `false` |
| `string` | `""` |
| Указатели | `nil` |
| Слайсы, карты, функции, каналы, интерфейсы | `nil` |
| Структуры | Значения полей по умолчанию |

Это важная особенность Go: локальные переменные нельзя использовать до объявления, а объявленные переменные получают определённое начальное значение.

Например, пустая строка — это не `nil`. У строкового типа нулевое значение `""`.

## 3. Константы

```go
const appName = "Go Concurrency Lab"
```

Константа обозначает значение, которое нельзя переназначить после объявления.

Константы полезны для фиксированных значений: названий, математических величин, конфигурационных значений, которые должны быть известны на этапе компиляции.

В отличие от переменных, константы Go могут быть объявлены с помощью `const`, но не могут содержать произвольные результаты вычислений, требующие выполнения программы во время работы.

## 4. Типы данных

Go — статически типизированный язык: у каждой переменной есть тип, который определяет допустимые значения и операции.

Среди базовых типов:

- `int`, `int8`, `int16`, `int32`, `int64` — целочисленные типы;
- `uint`, `uint8`, `uint16`, `uint32`, `uint64` — беззнаковые целые;
- `float32`, `float64` — числа с плавающей точкой;
- `bool` — логическое значение;
- `string` — строка байтов, обычно содержащая UTF-8;
- `byte` — псевдоним `uint8`;
- `rune` — псевдоним `int32`, часто используемый для представления кодовой точки Unicode.

### Преобразование типов

```go
var count int = 10
var ratio float64 = float64(count) / 4
```

Go не выполняет автоматическое преобразование между большинством числовых типов. Если требуется изменить тип, его указывают явно.

При этом преобразование может приводить к потере информации. Например, преобразование `float64` в `int` отбрасывает дробную часть.

Важно: преобразование типа — не то же самое, что форматирование значения в строку.

## 5. Арифметические операторы

Основные арифметические операторы:

- `+` — сложение;
- `-` — вычитание;
- `*` — умножение;
- `/` — деление;
- `%` — остаток от деления целых чисел.

Особенно важно понимать разницу между целочисленным делением и делением с плавающей точкой:

```go
fmt.Println(10 / 3)        // 3
fmt.Println(float64(10) / 3) // 3.333...
```

Если оба операнда — целые числа, результат деления также будет целочисленным, и дробная часть не сохраняется.

Операторы сравнения: `==`, `!=`, `<`, `>`, `<=`, `>=`. Они возвращают значение типа `bool`.

Логические операторы:

- `&&` — логическое И;
- `||` — логическое ИЛИ;
- `!` — логическое НЕ.

## 6. Условия

```go
if age >= 18 {
    fmt.Println("Adult")
} else {
    fmt.Println("Underage")
}
```

`if` позволяет выполнить код в зависимости от логического условия.

В Go условие не оборачивается в круглые скобки. Фигурные скобки обязательны.

Можно объявить переменную прямо в условии:

```go
if score := 100; score >= 60 {
    fmt.Println("Passed:", score)
}
```

Переменная `score` доступна в условии и в соответствующих ветках `if`/`else`, но не за пределами конструкции.

## 7. Циклы

В Go используется ключевое слово `for`.

```go
for i := 1; i <= 3; i++ {
    fmt.Println(i)
}
```

Здесь:

1. `i := 1` — начальное значение;
2. `i <= 3` — условие продолжения;
3. `i++` — изменение счётчика после итерации.

Go также поддерживает циклы с одним условием и бесконечные циклы. Позже мы разберём `range` для перебора коллекций.

## 8. Область видимости

Область видимости определяет, где доступно имя переменной.

```go
if score := 100; score >= 60 {
    fmt.Println(score)
}
```

Переменная `score` существует только в пределах области видимости конструкции `if`.

Локальные переменные помогают ограничивать состояние программы и не допускать случайного использования значений вне места, где они нужны.

1. Объяви переменные для имени, возраста, количества решённых задач и наличия опыта коммерческой разработки.
2. Выведи их значения, а затем измени их.
3. Создай две целочисленные переменные и выведи результаты всех арифметических операций.
4. Сравни `10 / 3` и `float64(10) / 3`. Объясни разницу.
5. Напиши условие, которое выводит, является ли число положительным, отрицательным или нулём.
6. Напиши цикл, выводящий числа от 1 до 10.
7. Объяви переменную внутри `if` и попробуй обратиться к ней после завершения блока. Объясни результат.
8. Найди пример, где явное преобразование числового типа может привести к потере информации.
