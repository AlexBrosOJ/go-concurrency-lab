# Функции в Go

## Цель модуля

Функции позволяют разделять программу на логические части, повторно использовать код и явно определять входные и выходные данные.

В этом модуле мы подробно изучим:

- объявление и вызов функций;
- параметры и возвращаемые значения;
- несколько результатов;
- именованные возвращаемые значения;
- variadic-функции;
- передачу аргументов по значению;
- указатели и изменение данных;
- функции как значения;
- функции высшего порядка;
- анонимные функции;
- замыкания;
- рекурсию.

Эти темы необходимы для дальнейшего изучения слайсов, структур, интерфейсов, обработки ошибок и конкурентного программирования.

## 1. Объявление функции

Общая форма объявления функции:

```go
func functionName(parameters) returnType {
    // function body
}
```

Например:

```go
func add(a int, b int) int {
    return a + b
}
```

Здесь:

- `func` — ключевое слово для объявления функции;
- `add` — имя функции;
- `a` и `b` — параметры;
- `int` после параметров — тип возвращаемого значения;
- `return` — возвращает результат вызывающему коду.

Вызов:

```go
result := add(10, 20)
```

Функция получает аргументы `10` и `20`, складывает их и возвращает `30`.

### Группировка параметров

Если несколько параметров имеют один тип, тип можно указать один раз:

```go
func multiply(a, b int) int {
    return a * b
}
```

Это эквивалентно:

```go
func multiply(a int, b int) int {
    return a * b
}
```

Такая запись часто встречается в Go-коде.

## 2. Возвращаемые значения

Функция может возвращать значение, которое используется вызывающим кодом.

```go
func square(number int) int {
    return number * number
}
```

Если функция объявлена с возвращаемым типом, она должна вернуть значение этого типа на всех допустимых путях выполнения.

Функция без возвращаемого значения может просто выполнять действия:

```go
func printMessage(message string) {
    fmt.Println(message)
}
```

### Несколько возвращаемых значений

Go позволяет возвращать результат и ошибку из одной функции:

```go
var errDivisionByZero = errors.New("division by zero")

func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errDivisionByZero
    }

    return a / b, nil
}
```

Вызов:

```go
quotient, err := divide(17, 5)
```

Тип `float64` сохраняет дробную часть результата. При нулевом делителе функция возвращает `errDivisionByZero`; вызывающий код может проверить её через `errors.Is`. Иначе возвращаются частное и `nil`.

Несколько возвращаемых значений особенно часто используются для передачи результата и информации об ошибке.

## 3. Результат и признак успешного выполнения

Функция может возвращать значение и дополнительный признак:

```go
func findMax(numbers []int) (int, bool) {
    if len(numbers) == 0 {
        return 0, false
    }

    max := numbers[0]

    for _, number := range numbers[1:] {
        if number > max {
            max = number
        }
    }

    return max, true
}
```

Второе значение `bool` показывает, удалось ли найти результат.

```go
max, ok := findMax(numbers)

if ok {
    fmt.Println(max)
}
```

Такой подход часто встречается в Go. Например, при чтении значения из карты:

```go
value, ok := myMap["key"]
```

Если ключ существует, `ok` будет `true`. Если ключа нет — `false`.

## 4. Именованные возвращаемые значения

Go позволяет объявить имена возвращаемых значений:

```go
func rectangleArea(width, height float64) (area float64) {
    area = width * height
    return
}
```

Здесь `area` — именованное возвращаемое значение.

Оно автоматически инициализируется нулевым значением своего типа. В теле функции мы присваиваем ему результат вычисления.

`return` без выражения называется naked return: функция возвращает текущие значения именованных результатов.

### Стоит ли использовать naked return?

Для коротких функций именованные результаты могут быть удобны. Но в длинных функциях naked return часто ухудшает читаемость: не сразу понятно, какие именно значения возвращаются.

Поэтому обычно лучше писать явный `return value`, если это делает код понятнее.

## 5. Variadic-функции

Variadic-функция принимает переменное количество аргументов одного типа.

```go
func sum(numbers ...int) int {
    total := 0

    for _, number := range numbers {
        total += number
    }

    return total
}
```

Можно вызвать её с разным количеством аргументов:

```go
sum()
sum(1)
sum(1, 2, 3)
sum(1, 2, 3, 4, 5)
```

Параметр `numbers ...int` внутри функции доступен как слайс `[]int`.

### Передача слайса в variadic-функцию

```go
values := []int{10, 20, 30}

sum(values...)
```

Оператор `...` передаёт элементы слайса как отдельные аргументы variadic-функции.

Важно: variadic-параметр может быть только один, и он должен находиться последним в списке параметров.

Например:

```go
func logMessage(prefix string, values ...int) {
    // ...
}
```

## 6. Передача аргументов по значению

В Go аргументы функций передаются по значению.

Это означает, что функция получает копию переданного значения.

```go
func changeCopy(value int) {
    value = 99
}
```

Вызов:

```go
value := 10
changeCopy(value)

fmt.Println(value) // 10
```

Внутри функции `changeCopy` переменная `value` — отдельная копия. Изменение этой копии не влияет на исходную переменную.

Это важная особенность Go: язык не передаёт обычные параметры по ссылке автоматически.

## 7. Указатели и изменение исходного значения

Указатель хранит адрес значения в памяти.

```go
func changeOriginal(value *int) {
    *value = 99
}
```

Здесь:

- `*int` — тип указателя на `int`;
- `&value` — получение адреса переменной;
- `*value` — обращение к значению по адресу.

Вызов:

```go
value := 10

changeOriginal(&value)

fmt.Println(value) // 99
```

Функция получает копию адреса, но этот адрес указывает на исходную переменную. Поэтому изменение значения через указатель влияет на исходные данные.

### Важная формулировка

Go всё равно передаёт аргумент по значению. В случае указателя копируется сам адрес.

Это не означает, что указатели являются отдельным механизмом передачи параметров по ссылке.

## 8. Функции как значения

В Go функции являются значениями. Их можно присваивать переменным, передавать в другие функции и возвращать из функций.

```go
func square(number int) int {
    return number * number
}

operation := square

fmt.Println(operation(6))
```

Переменная `operation` хранит функцию `square`.

Тип функции определяется её параметрами и возвращаемыми значениями. Например, `func(int) int` — функция, которая принимает `int` и возвращает `int`.

## 9. Функции высшего порядка

Функция высшего порядка — функция, которая принимает другую функцию в качестве аргумента или возвращает функцию.

```go
func apply(number int, operation func(int) int) int {
    return operation(number)
}
```

Вызов:

```go
result := apply(6, square)
```

В этом примере `apply` получает число и функцию, применяет её к числу и возвращает результат.

Функции высшего порядка полезны для:

- передачи поведения;
- callback-функций;
- обработки данных;
- настройки алгоритмов;
- уменьшения дублирования кода.

В Go этот подход часто встречается в middleware, обработчиках HTTP-запросов и тестировании.

## 10. Анонимные функции

Анонимная функция — функция без имени.

```go
func() {
    fmt.Println("Hello")
}()
```

Последние `()` означают, что функция вызывается сразу после объявления.

Анонимные функции можно использовать, когда небольшое действие нужно выполнить в одном месте или передать в другую функцию.

Например:

```go
func run() {
    message := "Hello"

    func() {
        fmt.Println(message)
    }()
}
```

Внутренняя функция имеет доступ к переменной `message`, объявленной во внешней функции.

## 11. Замыкания

Замыкание — функция, которая может обращаться к переменным из окружающей области видимости и сохранять доступ к ним после завершения внешней функции.

```go
func newCounter() func() int {
    counter := 0

    return func() int {
        counter++
        return counter
    }
}
```

Вызов:

```go
counter := newCounter()

fmt.Println(counter()) // 1
fmt.Println(counter()) // 2
fmt.Println(counter()) // 3
```

`newCounter` создаёт локальную переменную `counter` и возвращает функцию, которая использует эту переменную.

Несмотря на то что `newCounter` завершилась, возвращённая функция продолжает обращаться к сохранённому состоянию.

### Независимые замыкания

```go
counterA := newCounter()
counterB := newCounter()
```

Каждый вызов `newCounter` создаёт собственное состояние.

Поэтому вызов `counterA()` не меняет значение, которое хранится внутри `counterB`.

Замыкания полезны для создания функций с состоянием, callback-ов и небольших локальных механизмов без необходимости создавать отдельный тип.

## 12. Рекурсия

Рекурсия — ситуация, когда функция вызывает саму себя.

```go
func factorial(number int) int {
    if number <= 1 {
        return 1
    }

    return number * factorial(number-1)
}
```

Факториал числа:

\[
n! = n \cdot (n-1)!
\]

Например:

\[
5! = 5 \cdot 4 \cdot 3 \cdot 2 \cdot 1 = 120
\]

В рекурсивной функции обязательно должно быть условие завершения — базовый случай.

Без него вызовы будут продолжаться, пока программа не столкнётся с ограничениями ресурсов.

Рекурсия может быть удобна для деревьев, графов и некоторых алгоритмов. Но не всегда она лучше обычного цикла: важно учитывать глубину рекурсии и сложность решения.
