# Пакеты и модули

## Цель

Собрать запускаемую программу из двух пакетов в одном модуле. На примере подсчёта слов и рун разберём импорт, экспорт, `internal` и тестирование через публичный API.

## Запуск из корня репозитория

```bash
go run ./00-fundamentals/09-packages-and-modules
go test -v ./00-fundamentals/09-packages-and-modules/...
```

## 1. Где проходят границы

| Элемент | Роль |
|---|---|
| Корневой `go.mod` | Объявляет модуль `go-concurrency-lab` и версию Go |
| `main.go` в этом уроке | Исполняемый пакет `main` |
| `internal/textstats/stats.go` | Пакет `textstats` со статистикой текста |
| `internal/textstats/stats_test.go` | Тест в отдельном пакете `textstats_test` |

Пакет объединяет код в одном каталоге. Обычные исходные файлы каталога имеют одно имя пакета. Для тестовых файлов Go допускает отдельный пакет с суффиксом `_test`. Модуль объединяет пакеты и задаёт базу их путей импорта. В этом уроке используется существующий корневой `go.mod`.

Полный путь импорта складывается из имени модуля и пути каталога пакета относительно его корня:

```go
import "go-concurrency-lab/00-fundamentals/09-packages-and-modules/internal/textstats"
```

Имя в коде — `textstats`, поэтому вызов выглядит как `textstats.Analyze(input)`. Стандартные пакеты `strings` и `unicode/utf8` входят в Go. Дополнительных зависимостей для примера нет.

## 2. Экспорт и internal

Имена `Analyze`, `Summary` и поля структуры начинаются с заглавной буквы и доступны импортирующему коду. `countWords` начинается со строчной и остаётся внутри пакета.

Каталог `internal` ограничивает сам импорт. Импортировать `internal/textstats` могут пакеты внутри дерева, корень которого — каталог непосредственно над `internal`. Здесь это каталог урока, включая его подпакеты. Например, соседний урок про дженерики находится вне этого дерева, хотя принадлежит тому же модулю.

Экспорт отвечает за доступность имени после импорта. `internal` отвечает за то, будет ли разрешён импорт. Тестовый пакет `textstats_test` находится в нужном дереве и проверяет поведение через экспортированную функцию.

## 3. Проверка через открытый API

`Analyze` возвращает число слов по `strings.Fields` и число рун по `utf8.RuneCountInString`. Пробелы учитываются в числе рун. Слова разделяются пробельными символами, поэтому в тесте есть и неразрывный пробел. Число рун может отличаться от числа воспринимаемых символов в строке с составными знаками.

Ожидаемый вывод:

```text
=== Вызов функции из другого пакета ===
"Go lab": слов 2, рун 6
"ёж и кот": слов 3, рун 8
"": слов 0, рун 0
```

Суффикс `/...` в команде тестирования включает подпакеты. Без него Go проверит только исполняемый пакет урока, а тест находится в пакете статистики. Пакеты могут импортировать друг друга по направленной цепочке, а циклические импорты компилятор отклоняет.

## Попробуй самостоятельно

1. Добавь поле `Bytes` и проверь строку с кириллицей.
2. В отдельной ветке эксперимента попробуй вызвать `textstats.countWords` из `main`, затем объясни ошибку доступа.
3. Сравни `go test` для одного каталога урока и для него вместе с подпакетами.
4. Представь, что статистика понадобилась двум урокам. Как нужно разместить общий `internal`, чтобы оба урока могли его импортировать?

### 1. Понимание

Чем модуль отличается от пакета в этом уроке?

<details>
<summary>Показать ответ и объяснение</summary>

`go.mod` задаёт модуль и префикс путей импорта. Пакет объединяет файлы Go в одном каталоге с общим объявлением `package`. Здесь под одним модулем есть исполняемый пакет `main` и импортируемый пакет `textstats`. В том же каталоге внешние тесты могут объявлять отдельный пакет `textstats_test`.

</details>

### 2. Вывод кода

Что напечатает `fmt.Println(stats.Words, stats.Runes)` после `stats := textstats.Analyze("ёж и кот")`?

<details>
<summary>Показать ответ и объяснение</summary>

`3 8`. `strings.Fields` выделяет три слова. Подсчёт рун включает оба пробела, поэтому получается восемь.

</details>

### 3. Вывод кода

Что покажет `fmt.Println(stats.Words, stats.Runes)`, если вместо этого передать строку Go `"Go\u00a0lab"`?

<details>
<summary>Показать ответ и объяснение</summary>

`2 6`. Неразрывный пробел разделяет слова для `strings.Fields` и занимает одну руну. Всего здесь 2 + 1 + 3 руны.

</details>

### 4. Типичная ошибка

Почему соседний урок не может импортировать этот `internal/textstats`, хотя `Analyze` экспортирована?

<details>
<summary>Показать ответ и объяснение</summary>

Импорт пакета под `internal` разрешён внутри дерева родителя этого каталога. Здесь родитель — сам урок о пакетах. Заглавная буква делает имя доступным после разрешённого импорта.

</details>

### 5. Типичная ошибка

Почему `go test ./00-fundamentals/09-packages-and-modules` не запускает `TestAnalyze`?

<details>
<summary>Показать ответ и объяснение</summary>

Команда выбирает только пакет `main` в каталоге урока. `TestAnalyze` лежит в подпакете. Чтобы включить его, добавь к пути `/...`.

</details>
