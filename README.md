# Go Concurrency Lab

Практический учебный репозиторий по конкурентности в Go, ориентированный на написание кода, подготовку к собеседованиям и обучение новичков.

## Цели проекта

- Изучать конкурентность в Go на практике, самостоятельно пиша и запуская код.
- Разобраться в горутинах, каналах, синхронизации и отмене операций.
- Освоить распространённые паттерны конкурентности и их применение в реальных проектах.
- Подготовиться к собеседованиям на Go Backend-разработчика: от основ до тем уровня Middle.
- Предоставить новичкам понятные примеры, объяснения и практические задания.

## План обучения

### 01. Горутины

- Запуск горутин.
- Жизненный цикл горутин.
- `sync.WaitGroup`.
- Гонки данных.
- Типичные ошибки при работе с замыканиями и общим состоянием.

### 02. Каналы

- Небуферизированные и буферизированные каналы.
- Отправка и получение значений.
- Закрытие каналов.
- Чтение из каналов с помощью `range`.
- `select` и таймауты.
- Нулевые каналы и взаимные блокировки (deadlocks).

### 03. Паттерны конкурентности

- Fan-in — объединение нескольких каналов в один.
- Fan-out — распределение задач между несколькими обработчиками.
- Pipeline — конвейерная обработка данных.
- Worker pool — пул воркеров для обработки задач.
- Ограничение параллелизма.
- Сбор результатов параллельных операций.

### 04. Координация и отмена операций

- `context.Context`.
- Отмена операций и установка дедлайнов.
- Корректное завершение работы (graceful shutdown).
- Реализация семафоров.

### 05. Синхронизация

- `sync.Mutex` и `sync.RWMutex`.
- `sync.Once`.
- `sync.Cond`.
- `sync/atomic`.
- `sync.Map`.

### 06. Практические примеры

- Параллельные HTTP-запросы.
- Ограничение частоты запросов (rate limiting).
- Повторные попытки и таймауты.
- Фоновые задачи.
- Обработка задач с ограничением параллелизма.

### 07. Внутреннее устройство Go

- Планировщик GMP.
- Планирование выполнения горутин.
- `GOMAXPROCS`.
- Профилирование и трассировка.
- Особенности производительности.

### 08. Подготовка к собеседованиям

- Задачи на написание кода.
- Поиск и исправление ошибок в конкурентном коде.
- Разбор и ревью кода.
- Вопросы для собеседований и дополнительные вопросы по теме.

### 09. Алгоритмы и структуры данных

В планах: отдельный раздел с алгоритмическими задачами, включая задачи в стиле LeetCode.

## Как работать с репозиторием

Изучайте темы последовательно, следуя плану обучения.

Для каждой темы:

1. Прочитайте объяснение.
2. Запустите пример.
3. Попробуйте предсказать результат до запуска программы.
4. Выполните практическое задание, не заглядывая в готовое решение.
5. Запустите тесты.
6. Попробуйте объяснить вслух, как работает реализация и какие у неё есть компромиссы.

## Требования

- Go — версия указана в `go.mod`.
- Git.

## Команды

Запустить пример:

```bash
go run ./03-concurrency-patterns/01-fan-in
```

Запустить все тесты:

```bash
go test ./...
```

Запустить тесты с детектором гонок данных:

```bash
go test -race ./...
```

Отформатировать Go-код:

```bash
gofmt -w .
```
